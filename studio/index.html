How each new project is created

01
Describe the WBS

Tell ChatGPT the scope, divisions, tasks and the construction method—or provide drawings or a schedule.

02
Normalize the source

Build WBS IDs, activity IDs, FK relationships and evidence. Identify unknown durations, quantities and resource assumptions explicitly.

03
Generate reproducible files

Generate an Excel workbook, canonical JSON, and supported Primavera P6 exchange files using the same validated model.

04
Instantiate the project record

Supply one validated project dataset to the shared CPM kernel and four-view renderer. No cloned algorithms or hand-typed dates.
