Organic constellation, Gantt, calendar events when dates exist and source-defined checklists. AI-proposed source changes are validated offline; Actions rebuilds the project projections. Pages cannot edit project data.

Git-blob-pinned source snapshots, SHA-256 model readback, Pages privacy allowlist and regression suites. Source files and actual field approvals are not automatically publicized.

AI-first rule: You describe changes in ChatGPT; a validated source revision plus GitHub Actions updates read-only Pages. Never infer approved completion, site resource quantity, actual cost or contractual dates from an unapproved WBS.
