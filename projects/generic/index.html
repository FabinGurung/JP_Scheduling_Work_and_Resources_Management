One schedule. Four consistent views.

This studio reads the same calculated project model for the constellation, Gantt, calendar and checklist. Change the project, and the WBS and views change together—without inheriting Narayani's activity list.

Safety: Both included projects are deliberately synthetic. Durations are assumed, all approvals remain false, and the calendar shows scheduled events rather than actual daily construction progress. A locally selected compiled model stays in your browser and is never uploaded.

Only SKYFORGE_GENERIC_VIEW_MODEL_V1 with PUBLIC_SYNTHETIC_DRAFT_ONLY is accepted. Raw WBS files need server-side compilation and source review; this form does not make engineering decisions.
